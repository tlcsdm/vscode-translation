# Changelog

All notable changes to the "Translation" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-07

### Added
- Initial release
- Tencent Cloud Translation support
- Baidu Translation support
- Youdao Translation support
- Context menu translation under tlcsdm submenu
- Keyboard shortcut (Ctrl+Alt+T)
- Translation View panel
- Status bar engine switching
- Configurable settings (default engine, languages, API credentials)
